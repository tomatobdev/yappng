# Yappng

Hold a key, speak, and your words are typed into whatever app you're using. Transcription runs locally on your computer.

This repository hosts Yappng's public downloads and auto-updates. Get the latest version from the [Releases](https://github.com/tomatobdev/yappng/releases/latest) page:

| Platform | Download |
|---|---|
| Mac with Apple Silicon (M1 and later) | [Yappng-macOS-AppleSilicon.dmg](https://github.com/tomatobdev/yappng/releases/latest/download/Yappng-macOS-AppleSilicon.dmg) |
| Mac with Intel | [Yappng-macOS-Intel.dmg](https://github.com/tomatobdev/yappng/releases/latest/download/Yappng-macOS-Intel.dmg) |
| Windows 10/11 (most PCs) | [Yappng-Windows-x64-setup.exe](https://github.com/tomatobdev/yappng/releases/latest/download/Yappng-Windows-x64-setup.exe) |
| Windows on ARM (Snapdragon) | [Yappng-Windows-ARM64-setup.exe](https://github.com/tomatobdev/yappng/releases/latest/download/Yappng-Windows-ARM64-setup.exe) |

Installed copies update themselves automatically.
